Video Stream Processor Architecture

High-Level Design (HLD) - System Architecture

🌐 Presentation Layer

  • Flask Blueprints: upload_bp, update_bp
  • REST Endpoints: /upload-video, /upload-csv, /mjpeg-stream
  • Control APIs: /toggle-playback, /seek-frame, /save-logs
  • MJPEG Streaming: multipart/x-mixed-replace protocol
  • File Handlers: Video/CSV upload processing
  • Response Formats: JSON status, Binary streams

⚙️ Business Logic Layer

  • StreamProcessor: Singleton pattern with global state
  • Video Engine: Frame extraction, seeking, playback control
  • Annotation System: Dynamic bounding box overlay
  • ID Filter Engine: Include/exclude modes with real-time switching
  • Thread Coordinator: Multi-lock synchronization manager
  • State Manager: Playback position, filter settings, CSV mappings
  • Format Converter: Video → JPEG → MJPEG pipeline

💾 Data Access Layer

  • OpenCV Interface: cv2.VideoCapture with buffer management
  • Pandas Engine: CSV processing with DataFrame operations
  • File System: Temporary storage, video/CSV persistence
  • Memory Management: Frame caching, position tracking
  • Lock Infrastructure: RLock hierarchy (video, csv, frame, filter)
  • Resource Cleanup: Automatic deallocation and recovery
🔄 Data Flow: HTTP Request → Flask Router → Singleton Access → Thread-Safe Processing → OpenCV/Pandas Operations → Memory Buffer → JPEG Encoding → MJPEG Stream → HTTP Response → Browser Rendering

What: StreamProcessor with video processing

🔄 HLD-LLD Bridge: Each HLD layer defines WHAT the system should do, while LLD components specify HOW it's implemented. The interaction flows through well-defined interfaces: Flask routes → Singleton access → Thread-safe operations → Resource management.

🆕 Novel Aspects of This Implementation

🔀 Dynamic ID Switching

Real-time annotation updates without video reprocessing - uncommon in most streaming systems

🎯 Granular Lock Architecture

Four-level lock hierarchy (video/csv/frame/filter) enables fine-grained concurrency control

🔄 Hybrid Singleton Pattern

Global state with factory method + cleanup - balances simplicity with resource management

📊 CSV-Video Synchronization

Frame-accurate annotation correlation with live updates - typically requires specialized databases
